# Local Market Finder

Schau dir meine neue Seite https://localprices.bcsentinel.com/ an und erstelle mir dazu eine Top-WebApp. Ziel ist es Märkte miteinander zu vergleichen und dort die besten Angebote für Nutzer in einer optimalen Einkaufsliste zur Verfügung zu stellen. Es soll eine Map geben auf der man Märkte auswählen kann bzw. im Umkreis seines eigenen Standortes die Märkte sieht. Die App soll hochwertig und perfekt in UI/UX designt werden. Sie soll als professionelle WebApp nur für mobile Geräte genutzt werden. Wenn du weitere Fragen hast, dann melde dich.
